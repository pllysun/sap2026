# 1.5.26：执行过程实时推送与判题安全修复合并发布

2026-10-03，已部署至 https://csuftsap.top/oj。

## 行为与交互

编译与逐个样例运行现在分别发布真实阶段。用户端通过经过登录验证的 SSE 接收排队、资源分配、编译开始与结束、当前用例、用例结果和任务结束，并以紧凑步骤、旋转指示器、进度条和用例颜色展示。编译失败后不展示已运行样例，答案错误后未执行用例保持等待状态；节点切换会重置当前尝试的编译与用例进度。

弹窗关闭后任务和进度连接继续工作，切换结果、历史与排行使用同一条连接。离开页面或切换账号会取消连接。网络中断先重连，随后以现有结果查询兜底；最终状态以数据库保存的结果为准。完成后的近期结果可展开查看执行步骤。

进度只允许提交者订阅；平台验证任务不对用户提供进度。事件只包含阶段、时间、计数和用例判定，不包含代码、测试输入、期望输出或编译产物。身份令牌只在请求头传递。每账号最多 3 条连接、总计 128 条，状态缓存最多 256 个；发送使用独立任务和有界队列，慢客户端不会阻塞判题线程。进度接口沿用现有日志与接口统计体系，未调整日志记录策略、统计公式或热力图。

## 合并的判题内容

另一个会话《我们项目下有一个执行代码的虚拟机，是否存在有代码能够绕过的可能？审查报告发我。》已完成后，本次一并发布其 J01–J06 修复与启动隔离自检：请求协议和文件来源限制、HTTP/TLS 连接及读取限额、租约与编译产物归属、展示输出预算和节点响应流式限额。保留原始提交代码，输出展示截断不影响完整输出比较。

主服务与独立节点实际加载的 Agent SHA-256 均为 `b914cd233546cca771e6df96bdb793fb59f1aee9d2aa160bfe9221998cca9ed4`。独立节点的宿主 Agent 绑定文件已同步更新，原令牌、数据卷、端口、资源配置与权限保持一致。
