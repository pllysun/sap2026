# 管理端优化发布 1.4.102（2026-09-29）

## 变更

- 班级课表采集记录按原始采集时间倒序，不因恢复事件的新 ID 重新置顶。
- 采集结束自动刷新概览、教学日历、批次和已展开历史；网络失败自动重试并恢复任务跟踪。
- 成员页紧凑卡片、中文分页、清晰的选中页；详情弹窗按用户 ID 关联 12 类业务资料并分页，不包含日志或凭据。
- 设置页分为基础配置、身份管理、账号与安全、文件存储、网站展示；保留草稿，各区域独立保存。

## 候选版本撤回

- 发布校验发现本地 Maven 增量输出将开发数据库配置带入候选 1.4.101；该候选曾上传仓库，但未部署线上。
- 已删除候选标签及其平台、证明 manifest，仓库查询该标签返回 404；本机候选镜像和含配置的临时归档已清理。
- 对基础镜像的归档层检查确认，开发配置仅出现在候选新增层，不在 1.4.100 基础层。
- 新构建已排除本地配置，并验证构建脚本会拒绝含此类配置的预构建 JAR。
- 撤回镜像不能代替凭据轮换；需另行轮换开发配置中的数据库密码。本次未擅自修改数据库凭据。
