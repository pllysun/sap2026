# 1.5.39：算法题库题解

当前 75 道题均已完成并导入题解。先制定 `ops/judger/solutions/WRITING_STANDARD.md`，再由三位子 agent 各编写 25 篇，逐篇核对实际题面、样例、参考程序、复杂度与图解。

每篇统一包含读懂题目、解法思路、样例推演、实现步骤、为什么正确、复杂度、边界与常见错误、复盘练习八节。术语、变量与下标按入门读者解释；复杂过程提供可放大的 SVG 图解。全库共 53 幅图解。每个实际支持的做题模式包含带中文注释的 C、C++、Java、Python、Rust 代码，共 93 组模式、465 份程序。

用户端做题页增加题目 / 题解标签，手机端同步增加题解入口。通关代码的五语言标签位于代码块内，支持语法高亮、键盘切换、复制及放入编辑器。替换现有草稿需确认，切换题目与题解保留当前加载内容，切换账号清理题解缓存。图解弹窗居中，代码面板固定高度，兼容 320、390、768 像素视口和减少动态效果的设置。

管理端算法题库每题增加题解管理入口，支持八节正文编辑、SVG 预览、五语言代码切换、JSON 导入导出与保存。编辑正文独立滚动，保存按钮始终位于弹窗底部。题解内容使用独立的 `oj_solution` 表，按题目 ID 与题目版本唯一存储；保存题解不改变题面、参考实现、测试集、验证签名或题目版本。未来修改题目版本后需要整理并保存对应版本的题解。

题解接口要求登录和有效账号，并复用题目、题单的可见性及冻结版本规则。比赛结束前仅返回锁定状态，正文、SVG 与代码不会返回；服务端同时约束全部题目和其他题单入口，避免绕过比赛限制。比赛到达结束时间后自动开放题解，与是否公开参赛者代码相互独立。提前归档仍遵循结束时间。当前 5 道比赛题保持隐藏，比赛题单保持草稿，未设置或发布比赛时间；管理端可查看其题解。题解及 SVG 未放进公开静态资源，接口响应设置 private / no-store。
