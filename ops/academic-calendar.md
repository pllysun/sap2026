# 共享校历与当前课表入口

## 数据来源

- 校历按学期独立保存在 `sys_setting` 的 `term_start_<学期>` 项中，继续使用已有数据，不按个人账号或课表模式重复存储。
- 教务同步与班级采集先查询共享校历；缺失时才使用当前教务会话读取 `/jsxsd/jxzl/jxzl_query?xnxq01id=<学期>`。成功结果写库，失败不写空值。
- 班级课表学期表中的历史 `semester_start_date` 列不再读写。管理员修改共享日期后，查询接口直接返回共享值。
- App 校历独立缓存。教务、Web、班级的学期课表统一回填，手动修改过的日期及自建课表不受影响。
- Web 导入先查共享校历；缺失或服务器不可用时可继续从已登录的学校网页读取，不上传用户网页密码。

## 管理接口

- `GET /api/academic-calendar`：App 基础访问权限，返回公开的学期/日期数据。
- `GET /api/academic-calendar/admin`：管理员查看。
- `PUT /api/academic-calendar/admin`：管理员新增或编辑，参数 `term`、`semesterStartDate`。
- `DELETE /api/academic-calendar/admin/{term}`：管理员删除；下一次采集允许重新补全。
- 维护操作写入现有操作日志。管理入口位于软协课表 → 班级课表 → 教学日历维护。

## 班级目录与离线

- 固定层级为学期、学院、年级、专业、班级。院系目录来自真实数据，不硬编码学院/专业名称。
- 按学期持久缓存完整班级目录，24 小时内复用；“刷新目录”可强制更新。过期刷新失败仍可使用已有缓存。
- 已下载的课表仍按班级离线切换；主页不再展示更换课表卡片，入口留在课表设置。

## 当前解析边界

- 仅保留 `jwxt` 新版源站，不再连接已下线的 `jwgl`。
- 个人课表使用 `/jsxsd/xskb/xskb_list.do?viweType=0`，只解析 `qz-weeklyTable` 与 `courselists-item`。
- 删除旧 `kbtable/font`、推测 JSON 映射及路由别名探测，不把班级查询结果误作个人课表。
- WebVPN → 融合门户 → 教务的登录桥接不变；不要在超时后的教务登录页直接填密码。

本次只执行本地测试与测试 APK 构建，不执行模拟器验证或线上部署。共享校历接口及管理页面需要部署新版后端/管理端后生效。
