# 邮件弹窗定位回归检查

## 2026-09-06：滚动后弹窗裁切

根因：邮件页面使用 `zen-fade-in`，动画 `forwards` 保留了 `transform`。
未挂载到 body 的 Element Plus 弹窗因此以页面内容区作为固定定位包含块，
遮罩不能覆盖视口，页面滚动后弹窗顶部被裁切。仅调整弹窗高度不能解决。

修复：编辑、预览、测试发送三个弹窗统一 `append-to-body`；
通过 `email-modal` 按视口布局，标题和操作栏固定，内容区独立滚动。
邮件遮罩不再使用全局强制 z-index，保留 Element Plus 动态层级。

回归步骤：

1. 页面滚动到模板区域，再打开新增或编辑弹窗。
2. 确认遮罩覆盖整个视口，标题、关闭按钮、底部操作始终可见。
3. 滚动长表单，确认只有内容区滚动。
4. 从编辑器打开预览，确认预览在上层；关闭后编辑内容仍保留。
5. 检查 1440×900、1366×650、390×844 三种窗口尺寸。

不要用仅构建成功或容器健康代替上述浏览器验证。
