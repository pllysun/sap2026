# 1.4.90 App 注册 QQ 邮箱验证

2026-09-08 已完成代码、打包、部署和发送测试。生产容器 `sap` 使用 `pllysun/sap:1.4.90`，状态 healthy，重启次数 0。

## 功能

- Android 原生注册保留与 Web 相同的学号、密码、姓名、性别和 QQ 字段，增加 QQ 邮箱验证码、申请倒计时、图形挑战、错误提示和成功后回到登录页。
- App 独立接口 `/api/auth/app/register/email-code` 和 `/api/auth/app/register` 必须验证 QQ 邮箱；Web `/api/auth/register` 的规则保持独立。
- 验证码绑定学号和 QQ，六位数字、15 分钟有效、180 秒申请间隔、最多校验 5 次。摘要、额度和消费状态存入数据库，创建账号与消费验证码在同一事务。
- 新代码钩子 `APP_REGISTRATION_CODE` 与邮件模板 `app.registration-code` 自动初始化并绑定。线上模板 ID 为 7，启用状态已核对。注册成功仍调用 `ACCOUNT_REGISTERED`。
- 管理端可维护新钩子和模板。验证码邮件沿用加密队列、发送间隔和日志，失败内容隐藏，禁止重发旧验证码。配套六模板预览页已更新。
- Android 修复快速返回触发的导航异常，以及硬件回车按键在清除焦点后误触返回按钮的问题。
