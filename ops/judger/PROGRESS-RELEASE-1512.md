# 账户做题状态与 OJ 界面：1.5.12

2026-10-02，已部署到 https://csuftsap.top 。

## 本次变化

- 每个账号分别统计普通题库与各题单中的正式提交。题目前的编号或字母显示绿色通过标记、红色答案错误、黄色编译或运行异常；未有最终结果时显示蓝色判题动画。新任务等待期间保留上一次结果，样例运行和参考验证不改变做题标记。
- 在正式提交记录新增 `ever_accepted` 字段，启动时幂等补标历史 AC。通过以后，即使后续答案错误、运行异常或原记录被重判，做题标记保持绿色。题单成绩与罚时继续按有效判题结果重算。
- 进度接口只聚合当前账号、当前范围和当前已显示题目的少量字段，不读取或返回源码、题目快照和隐藏用例。普通题库提交统计、题目排名和性能比较均排除题单提交。
- 用户端页签按「全部题目 → 题单 → 提交记录」排列。题库与题单共用状态编号组件；已通过编号在鼠标悬停时也保留绿色。查看代码弹窗在桌面、平板和手机宽度下居中。
- 管理端题目、测试集、模板、题单、日志和节点管理共 60 个业务操作按钮使用统一样式与 SVG 图标；业务页签、时间线、模式切换和下拉操作也统一图标。
- 判题日志默认在浏览器用五种语言的实际格式化器展开源码，支持查看原始代码。保存的源代码不被展示格式化改变，加载期间显示状态，异步结果按任务校验，格式化失败时仍可读取原文。
