# 入门原创题 011–020

这 10 道题的题面、测试数据和参考实现为本项目原创，仅训练主题参考《算法竞赛入门经典（第二版）》的数组、字符串及模拟题型。[参考题单](https://vjudge.net/article/45)。每道题均为 `EASY`，只支持 `STDIO` 完整程序模式，不涉及链表；来源字段为“原创”，题面不含图片。

| 编号 | 题目 | 类型 | 重点边界 |
| --- | --- | --- | --- |
| 011 | 连续进步的记录 | 数组、模拟 | 相等算非下降、段在开头或结尾、单元素、全增与全降、10000 元素 |
| 012 | 循环轮值表 | 数组、模拟 | 向右方向、k=0、k=n、k>n、k=10^9、重复与负数、单元素 |
| 013 | 训练积分名次 | 排序、数组 | 并列名次后跳号、同分按编号排序、全同分、0 分与 10^9 分、2000 人 |
| 014 | 物资库的出入 | 模拟、基础数学 | 失败不扣库存、恰好清空、零初始库存、连续失败后成功、超过 32 位库存 |
| 015 | 分段温度调节 | 差分数组、前缀和 | 闭区间两端、整段和单点、负数与零增量、相互抵消、2000 次调节、超过 32 位结果 |
| 016 | 海报字母统计 | 字符串、计数 | 大小写合并、字母序打破并列、首尾空格、10000 字符、至少一个字母 |
| 017 | 值班留言的词数 | 字符串、模拟 | 连续空格、首尾空格、整行空格得 0、单个长词、最大 5000 词 |
| 018 | 连续标记压缩 | 字符串、模拟 | 相同字母隔开不得合并、最后一段、单字符、10000 字符连续与交替 |
| 019 | 灯位周边计数 | 二维数组、模拟 | 八邻格含斜角、角落边界不环绕、空与满网格、中心 8 灯、单行与单列 |
| 020 | 旋转数据表 | 二维数组、模拟 | 顺时针方向、长方形交换行列、单行与单列、50×50、负数与重复 |

每题 25 个不同测试：前 3 个 `sample:true` 公开样例，8 个明确边界用例，14 个固定种子随机用例。种子保存在本目录 `manifest.json`。输入均满足题面限制；第 017 题的全空格输入是题面明确允许的有效文本。

`generate.py` 中的独立 Python oracle 在生成时验证输入约束并计算输出。参考解使用与定义计算不同的构造：第 013 题 oracle 直接统计严格更高人数，第 015 题逐格应用操作，第 019 题按灯坐标的切比雪夫距离计数，第 020 题以反转行后转置得到结果。`validate.py` 再次检查题包 schema、公开样例、重复输入、全部 oracle 输出，并逐个实际执行参考代码。

```sh
python3 ops/judger/problem-packs/beginner-original/b/generate.py
node ops/judger/problem-packs/beginner-original/b/format.mjs
python3 ops/judger/problem-packs/beginner-original/b/validate.py --languages c cpp java python --rounds 3
```

本地验证已通过：Apple Clang 17 的 C17/C++17、Temurin JDK 21.0.7、Python 3.14.2，10 题 × 4 语言 × 25 用例 × 3 轮，共 3000 次实际执行；250 个 oracle 校验、10 个 schema 检查通过。详细结果及题包 SHA-256 在 `validation-local.json`。

五语言 starter 和 reference 共 100 个字段已使用项目 formatter 格式化，starter 仅提供输入输出骨架，不包含解法。Rust 参考代码已完成语法格式化，本机没有 Rust 编译器，尚未完成本地 Rust 执行。发布必须由主任务在实际 go-judge 环境使用 GCC 15.3、JDK 27、Python 3.14.7、Rust 1.98.1 做五语言三轮验证，全部通过后发布。
