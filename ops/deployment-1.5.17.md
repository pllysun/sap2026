# 1.5.17：用户端浏览器代码补全

2026-10-03，已部署到 https://csuftsap.top/oj。

用户端继续使用 CodeMirror 6。C、C++、Java、Python、Rust 支持关键字、代码片段、本文件变量与函数、作用域和常用标准库成员补全，增加参数提示、悬停说明和轻量语法提示。常用容器的提示显示已解析的元素类型；C++ 核心函数在输入未完成的成员表达式时仍保留参数信息。

分析在浏览器 Web Worker 中完成，不执行用户代码，也不上传输入中的代码。正式构建按所选语言加载解析器和补全数据，切换语言、进入只读状态或离开页面时终止旧分析线程。分析线程不可用时降级为对应语言的基础补全，编辑、运行和提交仍可使用。

编辑器增加自动括号、四空格缩进、折叠、查找替换和模板域跳转。补全快捷键为 Ctrl + Space 或 Alt + /，Tab 确认补全或切换模板域，Shift + Alt + F 格式化。外部格式化更新独立记录到撤销历史；账户、题目、语言与模式的现有草稿继续分别保存。只读提交代码不启动分析线程。

本次是用户端静态文件更新。后端 JAR、管理端、判题引擎和节点服务沿用 1.5.14 的原始文件；日志和统计相关 15 个受保护源码文件哈希保持一致，没有增加语言分析服务器或新端口。

浏览器分析覆盖本文件和常用标准库，复杂泛型、宏展开、完整类型检查与编译错误仍以服务器编译、判题结果为准。C 与 C++ 共用语法解析器，各自使用独立补全数据；语法提示不是编译器诊断。
