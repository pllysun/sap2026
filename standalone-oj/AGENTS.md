# AI 仓库操作规则

这是独立 Lume 算法题库，所有必需源码都在本目录。先读 `README.md`、`docs/AI_OPERATIONS.md` 和对应任务文档。

- 保留现有改动，不重置工作区。不要引用父级协会仓库的文件、数据库、环境变量、账号或生产判题节点。
- 根目录 `VERSION` 是独立镜像版本；合并镜像、网站镜像与独立判题镜像分别构建和验收。
- 不提交或打包 `.env`、`secrets/`、数据库、运行密钥、登录令牌、node_modules、target 和 dist。
- 账号只有超级管理员、题库管理员和练习用户三种可创建角色。学生代码在沙箱执行，不能在 AI 宿主机运行题包中的不可信代码。
- 题目必须包含完整题意、约束、公开样例、五语言初始代码、五语言参考实现和测试集。新增题包先用 `tools/ojctl.py lint`，再用服务器验证。
- 每个支持模式必须覆盖 C、C++、Java、Python、Rust。发布要求完整三轮验证通过；不得绕过验证、伪造签名或停用语言凑通过。
- 测试数据独立生成，固定随机种子，覆盖边界、随机和常见错误。复杂算法用独立暴力 oracle 做差分，保存覆盖与错误实现检查记录。
- 原创题来源写“软件协会原创”，不添加冗长来源说明；引用训练题型保留准确来源，不能复制官方隐藏测试。
- 题解遵守 `docs/SOLUTION_STANDARD.md` 的八节结构，五语言代码有注释，复杂过程使用可核验的安全 SVG。
- 修改题目必须携带当前 revision；冲突后重新读取。题解 revision 必须与题目一致。
- 比赛题面、隐藏测试、参考实现和题解权限由后端决定；不能通过 public 文件、前端代码或浏览器缓存提前泄露答案。
- 使用本项目私有配置和站点绑定令牌。不要输出凭据，也不把令牌转发到重定向站点。
- 完成用户已授权的操作，不重复请求同一授权；未授权的生产迁移、删除数据卷、发送消息或发布内容不扩大执行。
- 提交说明使用中文。交付报告区分源码已整理、构建已通过、数据已验证和镜像已发布，提供实际证据。
