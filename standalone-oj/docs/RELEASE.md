# 1.1.2 发布与验收

测试集编辑弹窗改为左侧用例列表、右侧单用例编辑，可搜索名称、管理样例和多个合法输出。弹窗高度随视口限制，列表与编辑区独立滚动，底部保存按钮固定，解决用例内容越出窗口及遮挡按钮的问题。用户题面同步显示多答案说明与参考输出标签。

新增三种判定方式：`ANY_OF` 接受预设的任一合法输出；`UNORDERED_LINES` 忽略行间顺序但保留行内顺序及重复次数；`SPECIAL_JUDGE` 通过隔离 Python 校验器按题意判断任意合法方案。原有标准比较与元素无序比较保持兼容。校验器异常、超时或返回类型错误计为 `SYSTEM_ERROR`，不会误记作用户 `WA` 或比赛罚时。具体协议、示例及 AI 验收步骤见 [MULTIPLE_ANSWERS.md](MULTIPLE_ANSWERS.md)。

## 本版验证

- 独立后端 155 项测试、用户端 68 项、管理端 2 项及 Python 工具 8 项通过；平台后端 1,101 项通过。
- 原生 Linux / cgroup v2，使用隔离 MySQL 8.4，无 Redis；首次启动题目数为 0，测试题仅导入隔离数据库，不随镜像预装。
- 合并版完成 615 次参考执行：原有元素无序 90 次、多个合法输出 210 次、自定义校验器 210 次、行无序 30 次、标准比较 45 次，以及运行时故障检查器的 30 次正常参考执行。五语言覆盖全部支持模式，均完成三轮验证。
- 分离版网站与独立判题机完成相同五种比较器的 585 次参考执行，覆盖五语言、全部支持模式与三轮验证。两种部署合计 1,200 次通过。
- 不同于参考输出的合法方案可 AC；重复索引、负下标、越界索引、多余输出、伪造 AC 和代码注入形式的输出均被拒绝。
- 校验器抛异常、非 bool 返回值、超时使验证失败，报告校验器 `SYSTEM_ERROR`；只在用户其他答案上发生的校验器故障同样报告 `SYSTEM_ERROR`。用户响应不泄露检查器源码与诊断细节。
- 保留 MySQL 与应用数据卷后，从合并版切换到分离版，原账号、MySQL 会话和题库均可继续使用；升级说明补充应用加密密钥与数据卷的保留要求。
- 平台已升级 `pllysun/sap:1.5.64`，健康检查通过；75 道现有题目元数据一致，139 个 HTML/JS/CSS 资源与本地构建一致，判题服务可用，正式 App 版本保持不变。
- 两套前端均完成生产构建。浏览器自动化工具本次连续超时，未完成实际截图验收；没有将静态构建检查描述为实际浏览器验收。

## 升级与 AI 操作

无需数据库字段迁移，也不需要重新导入现有题库。保留原 MySQL、私有配置和应用数据卷，按 [DEPLOYMENT.md](DEPLOYMENT.md) 更新镜像标签。已有题目的判定方式保持不变；使用新规则时，在“题目内容 → 答案判定”选择方式，填写用例的其他合法输出或 Python 校验器，保存后重新完成五语言三轮验证再发布。

新部署仍使用外接 MySQL，可按 Compose 显式启动同机 MySQL。RustFS/S3 是可选基础服务，连接信息放在私有配置中；业务设置继续在管理端维护。文档、源码压缩包均排除凭据、数据库、测试环境及构建缓存。
