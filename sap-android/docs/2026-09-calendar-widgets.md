# 月历、同步周末开关与桌面小组件

## 月历

- 与今日列表共用同名、同一天、同一起止节次的课程聚合规则；教师或教室不同不增加课程项数。
- 月历数字使用“课”表示课程安排数量；今日仍同时展示节次总数，避免课程项数与课时混淆。
- 连续无课日使用浅色连带，边缘圆角随区间变化，跨周区间在下方以完整起止日期显示。
- “无课”只来自课表数据，不宣称学校正式放假；缺少开学日期时提示补充，不误显示整月休息。
- “回到今天”仅在今日页选中非今天，或月历查看非本月时出现。
- 首页初始 Tab 保持课表（非导航栏第一个日历），模式变化后亦回到课表。

## 周末开关

- 默认关闭；教务同步、Web 导入、班级下载及有数据更新的后台班级刷新成功提交时，按当前课表底本是否存在周六/周日课程更新。
- 读取本地缓存、切换已有缓存、手动增删改课、校历补全、失败请求，以及版本未变化的后台探测均不更新开关。
- 用户之后可以手动关闭或开启，保留到下一次成功同步。
- 沿用现有设备级显示设置，仅更新 showWeekend，不覆盖配色、行高等其他设置。
- 后台提交校验登录人、当前来源及根数据版本，避免刷新时切换班级造成设置错写。

## 小组件

现有软协课表、下一节课、今日课程保留；新增今日概览、本周课量、月历。所有小组件读取本地缓存，兼容教务、Web、班级模式。显示聚合不影响用于通知的原始课程列表。

- 六款均配置独立 `previewLayout` 和 PNG `previewImage`，避免不支持布局预览的桌面回退为应用图标。
- 三款新 Provider 已加入统一刷新链路，缩放时重新绘制；月历按课程安排去重。
- 图片由 debug-only `WidgetPreviewActivity` 渲染 Android XML 生成，包含示例数据，不包含用户信息。
- 新组件最小高度考虑长课名以及六行月份，防止被桌面压缩后截断。

预览实现依据：[Android 官方小组件预览文档](https://developer.android.google.cn/develop/ui/views/appwidgets/previews?hl=zh-cn)。当前编译 SDK 34，提供布局及图片预览，不调用更高版本 SDK 的动态预览 API。

## 验证

- 154 项单元测试通过，Lint 无错误（仍有既有非阻断警告）。
- 隔离 `.classqa` 模拟器实际渲染六张预览；三款新组件 RemoteViews apply/reapply 无异常。
- 月历实际截图验证连续无课连带及今日高亮；切换下个月后出现“回到今天”。
- 本次仅修改 Android，无后端部署、无正式升级发布。
