# 软件协会 HTML 邮件模板

六套模板使用统一的青蓝视觉、表格布局和内联核心样式，使用协会官网 HTTPS Logo，不加载远程字体或脚本；收件客户端可能需要允许显示图片。窄屏样式为增强项。浏览器预览不等于 QQ、Outlook 等真实邮件客户端渲染。

## 文件与使用

- 打开 `preview.html`，选择模板、切换桌面/手机宽度、编辑示例变量后预览。
- 每个 `.html` 为未填变量的正式模板；复制到管理端的 HTML 内容字段。
- `templates.json` 是六个 EmailTemplateDTO 格式的请求对象；创建接口每次接收一个对象（不是整个数组）。
- `samples.json` 为纯虚构示例数据，链接仅指向站点首页供展示。
- 原有五份导入样例默认 `enabled: false`。App 注册模板默认启用，后端首次启动时自动创建并绑定；已有模板的编辑、停用、删除或解绑状态会保留。实际线上状态以管理端为准。
- 默认发件人显示名称为“中南林业科技大学软件协会”，通过管理端 SMTP 设置统一配置。注册与密码重置验证码邮件直接说明验证码用途，不展示“确认是你……”大标题。

## 模板与主题

- **注册成功 · 欢迎了解软件协会**：`account.registered`，主题：{{name}}，欢迎了解软件协会

- **修改密码 · 安全验证码**：`account.password-code`，主题：软件协会｜修改密码验证码

- **App 注册 · QQ 邮箱验证码**：`app.registration-code`，主题：软件协会｜App 注册邮箱验证码

- **加入协会 · 共同成长与进步**：`member.upgraded`，主题：{{name}}，欢迎加入软件协会

- **问题反馈 · 管理员回复提醒**：`app.issue-replied`，主题：你的问题有新回复｜{{issueTitle}}

- **学习小队 · 提醒管理员评分**：`study.review-reminder`，主题：待评分提醒｜{{teamName}} · {{taskTitle}}

## 变量

使用现有渲染器支持的 `{{variable}}` 语法，HTML 中的文本会被转义，不要传入 HTML 片段。

### account.registered

- `name`：示例 小林
- `associationIntro`：示例 软件协会是一群热爱技术、乐于分享的同学相聚的地方。 / 我们希望在这里一起交流想法、动手实践，在探索中发现兴趣，在协作中收获成长。欢迎你来了解我们，找到属于自己的方向。

### account.password-code

- `name`：示例 小林
- `account`：示例 lin@example.com
- `code`：示例 582 916
- `expiresInMinutes`：示例 10

### member.upgraded

- `name`：示例 小林

### app.registration-code

- `name`：本次注册姓名。
- `account`：本次注册学号。
- `email`：由本次 QQ 号生成的 `QQ号@qq.com`。
- `code`：后端生成的六位数字，仅用于正文。
- `expiresInMinutes`：15。

手机端使用 `APP_REGISTRATION_CODE` 钩子发送验证码，验证成功后调用既有 `ACCOUNT_REGISTERED` 成功钩子。Web 注册不使用邮箱验证码流程。验证码绑定学号和 QQ、15 分钟有效、最多校验 5 次、一次使用；同学号或 QQ 申请间隔 180 秒、每天最多 5 次，并有来源 IP 和全站限额。邮件走持久化加密队列与统一发送间隔，失败正文隐藏且不允许重发旧验证码。

### app.issue-replied

- `name`：示例 小林
- `issueId`：示例 128
- `issueTitle`：示例 切换班级课表后，课程显示没有更新
- `issueStatus`：示例 处理中
- `adminName`：示例 协会管理员
- `replyContent`：示例 我们已经复现了你反馈的问题，正在检查课表切换后的缓存刷新。 / 修复进展会在这条反馈中更新，感谢你的耐心与帮助。
- `repliedAt`：示例 2026-09-06 14:20

### study.review-reminder

- `adminName`：示例 小林
- `teamName`：示例 前端开发学习小队
- `taskTitle`：示例 第 3 周 · 完成一个响应式个人主页
- `pendingCount`：示例 6
- `taskDeadline`：示例 2026-09-08 23:59
- `remindedAt`：示例 2026-09-06 16:00
- `reviewUrl`：示例 https://csuftsap.top

所有变量发送前均需提供，当前渲染器不支持条件区块。日期由调用方格式化成中国标准时间，并使用清晰的年月日时分。任务没有截止时间时，`taskDeadline` 可填“未设置”。

## 接入注意

- 验证码样例仅用于展示；实际值、有效期必须来自后端验证逻辑，不可使用示例值。后端还需实现失效、单次使用、频控，模板不承担安全校验。
- 链接必须由业务端生成，校验为可信站点的 HTTPS 地址；不要接受用户任意提供的协议或跳转地址。HTML 转义不等于 URL 安全校验。
- 评分链接应替换成真实可访问的页面地址，不得把授权凭据放到链接中。问题反馈不提供网页链接，统一引导打开软协课表 App → 我的 → 意见反馈。
- 管理员回复使用纯文本；建议摘要有长度上限，完整内容在问题详情查看。收件人权限、问题归属和提醒去重由业务端校验。
- 注册邮件用于欢迎了解协会，`associationIntro` 是必填的纯文本协会介绍，支持换行；示例介绍需审核后使用。
- `member.upgraded` 仍用于会员升级成功事件，但只表达欢迎加入协会、共同成长与进步，不展示会员信息。
- 所有模板最底部固定署名“中南林业科技大学软件协会”。Logo 复用官网 `/admin/logo.png`，保留图片替代文字与文字标题。
- 协会口号固定为“万维网连接五大洲，二进制写尽天下事”。
- 催评邮件面向负责评分的管理员，不是催促学员提交。
- “请勿直接回复”适用于系统发件邮箱；如后续开通人工回信服务，应同步修改页脚。
